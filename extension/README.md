# MeritOS Chrome extension

1. Run or deploy the MeritOS web app.
2. In Chrome, open `chrome://extensions`.
3. Turn on **Developer mode**.
4. Choose **Load unpacked** and select this `extension` folder.
5. Sign in to MeritOS, finish profile setup, and select **Connect Chrome extension**.
6. Paste the generated connection key into the side panel.
7. Visit a grant, scholarship, or application form and select the MeritOS toolbar icon.

The extension scans visible form controls, including text fields, textareas, selects, radio groups, checkboxes, and Google Forms controls. It matches questions to verified profile facts, clearly marks missing context, and fills only checked suggestions. It never submits a form.

Before Chrome Web Store submission, package the contents of this folder (with `manifest.json` at the ZIP root), provide a public privacy policy, screenshots, a 1280×800 promotional image, and complete Google’s single-purpose and data-use disclosures. Store review and publication require the owner’s Chrome Web Store developer account.
