# MeritOS extension privacy summary

MeritOS reads visible labels, options, and editable controls on the application page the user opens. It sends a field question to the user’s connected MeritOS service only when the user requests AI analysis. The service returns answers grounded in the user’s verified profile.

The extension stores the MeritOS service URL and a revocable connection key in Chrome local extension storage. It does not sell applicant data, read unrelated browsing history, press Submit, or train models on private applicant content without a separate opt-in.

Users can revoke an extension connection from MeritOS and delete profile facts from their workspace. Sensitive or unsupported information is left blank.
